# Linear interaction modes

令 \(v=(\delta_C,w_A)\)，则：

\[
R_T-R_S=E_{CC}+E_{CA}+E_{AA},
\]
\[
E_{CC}=\delta_C^T\Delta M_{CC}\delta_C,\quad
E_{CA}=2\delta_C^T\Delta M_{CA}w_A,\quad
E_{AA}=w_A^T\Delta M_{AA}w_A.
\]

这是 `exact equality`。它表达 model-state × shift-block interaction；它不单独证明 block 是 canonical causal mechanisms。只有在 structural roles、允许 shift family 和坐标约束固定时，才使用 core/relation/nuisance 解释。
