# 3A Quotient 结构

shift lifting 的线性风险可见商写作

\[
\mathcal Q_{shift}^{visible}
=\operatorname{col}(\Psi)/
\bigl(\operatorname{col}(\Psi)\cap\ker\Phi\bigr).
\]

其维度由 response rank 给出；

\[
\dim(\text{shift-side blind})
=\operatorname{rank}(\Psi)-\operatorname{rank}(\mathsf R).
\]

对应的 model-side algebraic blind dimension 为

\[
\operatorname{rank}(\Phi)-\operatorname{rank}(\mathsf R).
\]

这里的 quotient 是 quadratic-risk lifting quotient，不等于 causal mechanism quotient，也不等于 latent semantic space。
