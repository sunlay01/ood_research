# 3A 子空间几何

shift groups 的 response columns 位于 \\(\mathbb R^{N_{model}}\\)，model groups 的 response rows 转置后位于 \\(\mathbb R^{N_{shift}}\\)。在各自 ambient space 内计算：

- group span rank；
- pairwise intersection dimension；
- principal angles；
- inclusion residual；
- incremental rank。

这些量只描述线性子空间关系。group name 是索引 metadata，不是机制命名。
