# Proofs

No accepted active theorem or formal proof is present yet. Baseline theorem attempts are kept in [`baselines/`](baselines/), and prior audits in [`audits/`](audits/). The [`active/`](active/) directory is intentionally empty until a framework-design decision promotes a theorem. New proofs must state the target quantity, information structure, assumptions, and every oracle or unidentifiable term. A proof that relies on an algorithmic response object must justify that bridge explicitly.
