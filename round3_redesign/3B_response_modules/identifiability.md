# Identifiability Boundaries

If response images form a direct sum, a response has a unique module
decomposition.  If two images intersect nontrivially, a nonzero intersection
vector can be assigned to either module.  If the images coincide, response-only
data cannot recover the generating label.  These are exact linear-algebra
claims and are independent of clustering performance.

The runner includes identical-image and partial-overlap counterexamples.  The
counterexample metadata is constructed after the blind experiment and is not
an input to discovery.
