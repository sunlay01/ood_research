# Assumptions

- Population linear square risk with a positive-definite source second-moment matrix.
- The observable task state is `psi_e=(svec(M_e),m_e,c_e)`.
- Source exposure is built only from registered source states and a source optimum.
- Target probes, oracle mechanism labels, 3B clusters and 3C regularizers are post-hoc.
- All rank statements use a declared relative SVD tolerance.
- No finite-sample, causal, deep-network or universal domain-generalization claim is made.
