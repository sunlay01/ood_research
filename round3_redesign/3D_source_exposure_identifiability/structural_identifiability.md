# Structural Identifiability

For world perturbations `u`, let `O_S u` be source observations and `A_T u`
be target response. The factorization criterion is

`ker(O_S) subset ker(A_T) <=> A_T = A_tilde O_S`.

The structural ambiguity dimension is

`dim ker(O_S) - dim(ker(O_S) intersection ker(A_T))`.

The hidden-emergent Gaussian pair sets source `U-Y` coupling to zero in both
worlds, then assigns opposite target coupling. Source moments are exactly the
same, while the target whitened response differs. This is a strict
source-identical counterexample to response identifiability.
