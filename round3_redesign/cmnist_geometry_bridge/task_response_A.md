# Task Response A

For each declared family direction, the target oracle head is computed from
the empirical target moments at positive and negative perturbations.  The
finite-difference head displacement is mapped by `H_S^(1/2)`, where
`H_S=2 M_S`, into the Round-3 response metric.

The report includes three step sizes, singular values, rank and per-seed
stability.  This is an empirical derivative of an oracle head, not a causal
effect and not a target-risk bound.
