# Active Task Protocol

No research task is active unless an explicit `active/TASK.md` exists.

If `active/TASK.md` exists, read it with `active/CONTEXT.md` after `AGENTS.md`
and `CURRENT_STATE.md`. If those files do not exist, do not infer an active
task from historical reports or previous chat.

Use the templates in this directory for new tasks:

- `TASK_TEMPLATE.md`
- `CONTEXT_TEMPLATE.md`
- `STATE_DELTA_TEMPLATE.md`
