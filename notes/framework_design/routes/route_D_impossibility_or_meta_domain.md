# Route D — Problem narrowing by impossibility or meta-domain target

- **Problem instance:** P1/P4 when no conditional bridge is available.
- **Formalization:** existing domain-risk meta-law theorem, or an indistinguishability lower bound.
- **Reuse/change:** reuse two-level concentration or lower-bound constructions.
- **Representation:** `g_f(P)=R_P(f)` for expected future-domain risk; no added representation for impossibility.
- **Required result:** characterize the fresh-domain tail or prove that a conditional term cannot be removed.
- **Assumptions:** iid/exchangeable `Pi`, finite domain complexity, or explicit indistinguishable worlds.
- **Source-estimable:** empirical source risks and complexity estimates.
- **Assumption-controlled:** `Pi` coverage and target quantiles.
- **Irreducible:** arbitrary-target non-identifiability.
- **Failure case:** identical source summaries with separated target risks.
- **Solved if successful:** a correctly scoped expected-domain theorem or a rigorous impossibility result that prevents overclaiming.
