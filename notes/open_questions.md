# Open theory questions

- What source-observable structure can define a non-vacuous admissible target family?
- Which assumptions are necessary for any source-only target-risk control?
- How should estimation error, approximation error, source heterogeneity, shift uncertainty, and irreducible transfer error be separated?
- Can a DG bound be tighter than generic domain-adaptation discrepancy bounds without using target data?
- Which impossibility examples show that source environments do not identify target behavior?
- When does an environment-variance or conditional-mechanism assumption support a valid decomposition?
- Which candidate representations remain stable under reparameterization of the hypothesis class?
- How should theorem tightness be compared across admissible target families?
