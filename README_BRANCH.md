# OOD algorithm branch

This branch isolates microscopic, operational mechanism research from macroscopic statistical OOD theory. Start with [`research_program.md`](research_program.md), [`historical_status.md`](historical_status.md), and [`migration_map.md`](migration_map.md).

The existing `src/`, `configs/`, `tests/`, and `round3_redesign/` paths remain available for reproducibility. The new directories classify their scientific role without silently changing their import paths or interpretation.

The companion branch `ood-theory` is intentionally sparse and does not inherit A/O/Pi, C/K, response-geometry, or matched-fork assumptions as foundational theory.
