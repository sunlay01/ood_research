# Original evidence layer

This directory stores downloaded papers and the source manifest. It is not a first-pass reading corpus.

- Use [`download_manifest.csv`](download_manifest.csv) to map citation keys to local files, source URLs, status, and page count.
- PDF files are authoritative primary evidence for theorem, definition, equation, and metadata checks.
- [`../ledger/`](../ledger/) is the compact index that decides which paper or detailed card needs to be opened.
- `Duchi2021.landing.html` is a retained publisher landing page; it is metadata support, not a paper PDF.
